# fly-cartpole

[English](README.md) · **한국어**

[MaleCNS v1.0](https://male-cns.janelia.org/) 커넥톰에서 시냅스 단위로 그대로 옮겨 온 초파리 뇌의
두 회로가 Gymnasium의 CartPole에서 막대기를 세웁니다. 초파리가 날면서 몸을 바로 세우는 데 쓰는
회로는 반사만으로 막대기를 세우고 랜드마크를 기준으로 제자리를 지킵니다. 시냅스는 하나도 바뀌지
않으며, 초파리가 각 감각에 얼마나 강하게 귀 기울일지 스스로 조율하고 나면 500걸음 상한에 도달하고,
네 배 길게 돌려도 95%의 에피소드에서 트랙 위에 머뭅니다.
초파리의 학습 중추인 버섯체(mushroom body) 두 개는 도파민이 조절하는 가소성으로 이 과제를 배워
평균 392.5걸음에 이릅니다. 웹 뷰어는 반사 초파리를 브라우저에서 실시간으로 돌리면서 비행 회로가
일하는 모습을 보여 줍니다.

![웹 뷰어: 왼쪽에는 수레와 막대기, 조향 신호, 감각 이득이, 오른쪽에는 MaleCNS 세포체 위치에 그린 비행 회로가 보입니다](assets/viewer.png)

## 반사 초파리

### 결과

**초파리가 날면서 몸을 바로 세우는 데 쓰는 회로를 실측한 배선 그대로 옮기면, 이 회로가 반사만으로
막대기를 세우고 랜드마크를 기준으로 제자리를 지킵니다. 초파리가 스스로 감각 이득을 조율하고 나면
500걸음 끝까지 버티며, 네 배 길게 돌려도 95%의 에피소드에서 트랙 위에 머뭅니다.** 시냅스는 하나도
바뀌지 않으며, 초파리는 각 감각에 얼마나 강하게 귀 기울일지만 조율합니다. 이전 실행이 한 번도
건드리지 않은 평가 시드 20개(180-199)의 결과는 다음과 같습니다.

| 조건 | 설명 | 마지막 100 평균 ± 표준편차, 500걸음 상한 | 2,000걸음 에피소드: 평균 길이 | 트랙 이탈 | 가운데에서 떨어진 평균 거리 |
|---|---|---|---|---|---|
| `fly-reflex-station-fixed` | 배선 그대로의 비행 회로와 랜드마크, 이득은 모두 1 | 353.7 ± 6.4 | 356 | 100% | 0.81 m |
| `fly-reflex-adaptive` | 자가 조율, 랜드마크 없음 | 499.9 ± 0.2 | 1,580 | 59% | 0.94 m |
| `fly-reflex-station` | **자가 조율, 랜드마크 있음** | **499.6 ± 1.4** | **1,982** | **5%** | **0.51 m** |

2,000걸음 에피소드는 CartPole-v1의 500걸음 상한을 넘겨서, 시드마다 10개씩 조율된 이득으로 탐색 없이
돌립니다. 상한 안에서는 두 자가 조율 초파리 모두 마지막 에피소드의 99% 이상이 500에 도달하므로,
제자리를 지키는 능력의 차이는 상한을 넘겨야 드러납니다. 시드별 평균에 대한 순열 검정
([results/station/summary.md](results/station/summary.md)) 결과, 랜드마크가 있으면 없을 때보다
막대기를 더 오래 세우고 수레를 가운데에 더 가깝게 유지하며, 랜드마크 초파리에게 자가 조율이 도움이
됩니다(각각 p = 0.0001). 상한 안에서는 두 자가 조율 초파리가 다르지 않은데(p = 0.76), 둘 다 천장에
닿아 있기 때문입니다. 자가 조율한 랜드마크 초파리는 시드 20개 중 15개에서 트랙을 한 번도 벗어나지
않았고, 랜드마크가 없는 초파리는 모든 시드에서 벗어났습니다.

### 랜드마크로 제자리 지키기

첫 반사 초파리는 수레가 어디에 있는지 알지 못했습니다. 수레를 가운데로 되돌리는 힘이 없어서 수레가
흘러갔고, 긴 에피소드의 59%가 트랙 밖에서 끝났습니다. 제자리에서 나는 곤충은 눈에 보이는 것을
기준으로 자리를 지킵니다. 그리고 파리는 옆으로 몸을 밀지 않습니다. 가려는 쪽으로 몸을 기울이고,
기울어진 추력이 몸을 그쪽으로 옮기게 합니다. 시각 조향도 날개를 직접 움직이기보다 평균곤 반사가
지키려는 자세를 바꾸는 방식으로 작동한다고 여겨집니다(Chan, Prete and Dickinson 1998). 랜드마크
초파리는 이 방식을 따릅니다. 트랙 가운데 위의 줄무늬가 수레의 위치를 알려 주고, 트랙 절반 폭(2.4 m)으로
나눈 수레 위치를 기울기와 같은 부호로 홑눈 구동에 더합니다. 가운데보다 오른쪽에 있는 수레는
오른쪽으로 기운 막대기처럼 읽히므로 초파리는 막대기를 왼쪽으로 기울인 채 유지하고, 그 기울기가
수레를 다시 가운데로 데려옵니다. 직관적인 반대 방식, 즉 가운데 쪽으로 미는 방식은 오히려 나쁩니다.
그 부호를 쓴 선형 반사는 탐색한 모든 에피소드에서 트랙을 벗어났습니다. 위치 이득은 초파리가
조율하는 네 번째 이득이며, 회로와 CartPole-v1은 그대로입니다.

랜드마크는 초파리가 홑눈에 충분히 귀 기울일 때에만 도움이 됩니다. 배선 그대로라면 평균곤 경로가
조향 신호를 움직이는 정도가 홑눈 경로의 약 48배이고, 이득이 모두 1이면 랜드마크도 그 약한 홑눈
경로를 탑니다. 그래서 고정 이득 초파리는 긴 에피소드에서 매번 트랙을 벗어났습니다. 조율은 평균곤에
견주어 홑눈을 키우고(평균곤 이득의 중앙값이 홑눈의 0.10이므로, 평균곤이 앞서는 정도가 약 48배에서
약 5배로 줄어듭니다), 그러면 랜드마크가 수레를 붙잡습니다.

### 랜드마크 없이 (시드 160-179)

랜드마크를 넣기 전의 첫 평가는 배선 그대로의 회로, 자가 조율, 섞은 회로에서의 자가 조율, 우연
수준을 비교했습니다. 감각 이득을 모두 1로 고정하면 초파리는 평균 275.6걸음을 버텼습니다. 막대기를
떨어뜨리지는 않았습니다. 시드마다 첫 에피소드를 보면, 20개 중 14개는 수레가 트랙을 벗어나서
끝났고 나머지 6개는 상한에 도달했습니다. 자가 조율을 하면 점수가 499.9로 올라갔습니다. 마지막 100
에피소드의 99.85%가 500걸음 상한에 도달했고, 가장 짧은 에피소드도 401걸음이었습니다.

([results/reflex/summary.md](results/reflex/summary.md)) 결과, 반사는 우연 수준을 넘어서고,
자가 조율은 도움이 되며, 실측 배선이 기여합니다(각각 p = 0.0001). 자가 조율의 학습률은 튜닝 시드
100-109에서 골랐습니다([results/reflex/tuning.json](results/reflex/tuning.json)). 그곳에서 여섯
설정이 모두 479-500점을 받았으므로, 결과가 이 값에 좌우되지는 않습니다. 평가에는 시드 160-179를
썼고, 랜드마크 초파리도 같은 학습률을 씁니다.

여전히 몸을 바로 세우는 부호로 날개 조향 운동 뉴런에 닿는지에 따라 나눌 수 있습니다.

|---|---|---|---|
| 교정 | 교정 | 4 | 499-500 |

실측 회로는 첫 번째 종류입니다. 자가 조율은 경로의 크기만 바꿀 수 있고 부호는 뒤집지 못합니다.
그래서 두 부호를 모두 지킨 섞인 회로는 실제 회로만큼 잘하고, 둘 다 뒤집힌 회로는 9걸음 만에
막대기를 밀어 넘어뜨립니다.

### 작동 방식

**커넥톰 조각.** `fly-cartpole extract-flight`는 초파리의 비행 안정화 감각 뉴런에서 날개 조향 운동
뉴런까지, 시냅스가 5개 이상인 연결을 3번 이하로 거치는 경로 위의 뉴런을 모두 남깁니다. 평균곤
구심 뉴런 203개(평균곤은 초파리의 자이로스코프입니다), 홑눈 뉴런 22개(홑눈은 수평선을 읽습니다),
HS 세포 8개(넓은 시야의 수평 움직임), 뇌와 복측 신경삭의 사이 뉴런 5,159개, 날개 조향 운동 뉴런
67개이며, 연결은 모두 191,953개입니다. 각 뉴런의 부호는 예측된 신경전달물질에서 가져옵니다
(아세틸콜린은 흥분, GABA·글루탐산·히스타민은 억제). 각 연결의 가중치는 시냅스 수를 시냅스후
뉴런이 받는 주석된 입력 전체로 나눈 값이므로, 모든 뉴런은 신경계 전체에서 이 회로가 차지하는
입력 비중을 그대로 유지합니다. 이 조각은 `data/flight.npz`로 커밋되어 있습니다.

**감각.** 막대기의 기울기는 초파리 몸의 옆기울임(roll)으로 읽습니다. 위로 들리는 쪽의 홑눈이
하늘을 더 많이 봅니다. 기울어지는 속도는 평균곤이 읽습니다. 아래로 내려가는 쪽의 평균곤이
흥분합니다. 수레의 속도는 HS 세포가 받는 수평 광류(optic flow)입니다. 각 감각은 작동 범위(0.21 rad,
3.5 rad/s, 3 m/s)로 나누고 ±1로 자른 뒤 이득을 곱합니다. 랜드마크는 2.4 m로 나눈 수레 위치에 자기
이득을 곱해 홑눈 구동에 더합니다.

**회로.** 새는 선형 발화율 단위를 씁니다. 활동은 기본 발화에서 벗어난 정도이므로 억제는 음의
활동입니다. CartPole 한 걸음마다 4번 갱신하고(누설 0.5), 에피소드마다 휴지 상태에서 시작합니다.

**조향.** b1과 b2 운동 뉴런은 날갯짓의 진폭을 키웁니다. 오른쪽으로 기우는 몸은 오른쪽 날개가 더
세게 칠 때 바로 서므로, 여기서는 이를 수레를 오른쪽으로 미는 것에 대응시켰습니다. 오른쪽의 b1과
b2가 왼쪽보다 더 활동하면 초파리는 오른쪽으로 밉니다.

**자가 조율.** 초파리는 에피소드마다 조금씩 다른 이득을 시도합니다. `log g = mu + eps`이고
`eps ~ N(0, 0.3²)`입니다. 에피소드가 끝나면 도파민은 최근 기록에 견준 에피소드 길이
`(길이 − 최근 20개 평균) / 최근 20개 평균`이 되고, 이득은 기록을 넘어선 시도 쪽으로 움직입니다
(`mu += 0.3 · 도파민 · eps / 0.3`). 바뀌는 것은 각 감각이 감각 뉴런을 얼마나 세게 구동하는지뿐입니다.

**조율이 바꾸는 것.** 회로는 선형이고 초파리는 조향 신호의 부호만 읽으므로, 모든 이득을 똑같이
키우거나 줄여도 아무것도 달라지지 않습니다. 의미가 있는 것은 이득 사이의 비율뿐이며, 뷰어는
기하평균이 1이 되도록 맞춰 보여 줍니다. 배선 그대로라면, 오른쪽으로 넘어지는 막대기가 평균곤을
거쳐 조향 신호를 움직이는 정도는 오른쪽으로 기운 막대기가 홑눈을 거쳐 움직이는 정도의 약 48배입니다.
HS 세포는 조향 운동 뉴런에 거의 닿지 않습니다(홑눈의 1/24). 이렇게 각속도가 지배하는 반사는
막대기가 넘어지는 것은 막지만 기운 상태는 거의 바로잡지 못해서, 수레가 트랙 밖으로 흘러갑니다.
뷰어가 돌리는 시드 0의 랜드마크 초파리는 상대 이득을 홑눈 3.30, 평균곤 0.36, HS 0.82, 랜드마크
1.02로 조율했습니다. 홑눈에 평균곤보다 약 9배 강하게 귀 기울이므로, 조향 신호에서 평균곤이 홑눈을
앞서는 정도가 약 48배에서 약 5배로 줄어듭니다.

### 실측한 것과 지어낸 것

- **실측:** 위 경로 위의 모든 연결과 그 시냅스 수, 각 뉴런의 예측 신경전달물질, 어떤 뉴런이 평균곤
  구심 뉴런·홑눈 뉴런·HS 세포·날개 조향 운동 뉴런인지, 세포체 위치.
- **지어냈거나 가정한 것:** CartPole을 비행에 대응시킨 방식(막대기 기울기를 몸의 옆기울임으로,
  기울어지는 속도를 평균곤 회전으로, 수레 속도를 광류로, 수레 위치를 랜드마크가 보이는 자리로),
  랜드마크 신호가 초파리가 지키는 자세를 바꾸는 형태로 홑눈 구동에 들어간다는 가정, 커넥톰에서 읽지 않은 유일한 부호인
  평균곤의 부호(교정 방향의 평균곤-b1 반사와 일치합니다; Dickinson 1999), b1·b2에 의한 조향과
  그것을 밀기에 대응시킨 것, 크기 조정에 쓴 작동 범위, 선형 발화율 단위와 그 시간 상수,
  신경전달물질의 부호(글루탐산과 히스타민은 어디서나 억제로 취급), 자가 조율 규칙과
  [results/reflex/hyperparameters.json](results/reflex/hyperparameters.json)의 학습률.

### 부족한 점

- 랜드마크 초파리도 여전히 흘러 다닙니다. 긴 에피소드에서 수레는 가운데에서 평균 0.51 m 떨어져
  있고, 5%는 트랙 밖에서 끝납니다. 이득은 CartPole-v1의 500걸음 에피소드에서 조율되는데, 이미
  500에 도달하는 초파리는 더 이상 도파민을 받지 못하므로, 막대기가 쓰러지지 않게 되면 위치 이득도
  더 나아지지 않습니다.
- 랜드마크 신호는 홑눈 뉴런에 바로 넣습니다. 이 신호를 눈에서 실어 나를 시각 경로는 회로에 들어
  있지 않습니다.
- 커넥톰은 화학 시냅스만 기록합니다. 반면 검정파리에서는 평균곤 구심 뉴런이 전기 시냅스로도 b1
  운동 뉴런에 닿습니다(Fayyazuddin and Dickinson 1996).
- 섞을 때 연결은 가중치와 함께 옮겨지므로, 섞인 회로의 뉴런은 실제 뉴런의 최대 입력 규모(0.98)의
  5.7배까지 입력을 받을 수 있습니다. 동역학은 안정적으로 유지되지만, "배선이 기여한다"는 비교에는
  연결 구조와 입력 규모가 함께 섞여 있습니다. 자가 조율의 학습률도 실제 회로에서 골라 섞인 회로에
  그대로 썼습니다.
- 선형 발화율 모델 하나만 씁니다. 스파이크도, 비행 회로의 신경 조절도, 머리와 목의 움직임도
  없습니다.
- 평균곤의 부호와 감각 크기 조정을 정한 탐색은 시드 100-159와 500-519에서, 튜닝은 시드 100-109에서,
  첫 평가는 시드 160-179에서, 랜드마크 평가는 시드 180-199에서 실행했습니다.

## 버섯체 초파리

이 저장소의 첫 번째 초파리는 학습합니다. 초파리의 학습 중추인 버섯체 두 개가 도파민이 조절하는
가소성으로 막대기 세우기를 배웁니다. 이 초파리의 실시간 뷰어는 반사 초파리의 뷰어로 바뀌었고,
git 기록의 커밋 `bd43325`에 남아 있습니다.

### 결과

**초파리는 막대기 세우기를 학습했고, 마지막 에피소드의 절반 가까이를 500걸음 끝까지
버팁니다.** 타고난 배선 그대로라면 초파리는 19걸음쯤 만에 막대기를 떨어뜨립니다
(`fly-bilateral-frozen`). 3,000 에피소드를 학습하고 나면, 이전 실험이 한 번도 건드리지 않은 평가
시드 20개에서 마지막 100 에피소드 동안 평균 **392.5걸음**을 버티며, 그중 46%는 500걸음 상한에
도달합니다. 스무 마리 중 열아홉 마리가 각자 CartPole-v0의 "해결" 기준(195)을 넘었고, 여섯 마리는
CartPole-v1의 기준(475)도 넘었습니다. 같은 보상 아래에서 같은 케년 세포(Kenyon cell)를 읽는
교과서적 TD actor-critic은 모든 시드에서 완벽하게(500) 균형을 잡았습니다. 즉 케년 세포 코드와
보상은 충분하며, 초파리를 붙잡고 있는 것은 학습 규칙입니다.

![학습 곡선](results/learning_curves.png)

| 조건 | 설명 | 마지막 100 에피소드 평균 ± 표준편차 (시드 20개) | 500걸음에 도달한 에피소드 |
|---|---|---|---|
| `fly-bilateral` | 버섯체 두 개, 예측 오차 도파민, push-pull 가소성 | **392.5 ± 103.1** | 46% |

[results/summary.md](results/summary.md)에 있습니다).

- 초파리가 학습합니다: `fly-bilateral` > `fly-bilateral-frozen`, p = 0.0001
- 우연 수준을 넘어섭니다: `fly-bilateral` > `random`, p = 0.0001
- 실측 배선이 도움이 된다는 증거는 없습니다: `fly-bilateral` > `fly-bilateral-shuffled`,
  p = 0.48. 섞기는 세포 수, 각 세포의 연결 상대 수, 각 도파민 뉴런이 닿는 위치를 그대로 두고,
  어느 케년 세포가 어느 세포와 연결되는지만 바꿉니다. 따라서 학습은 정확한 시냅스 지도가 아니라
  이 구조에서 나옵니다. 이전 평가들의 결과는 엇갈렸습니다(시드 0-9에서는 실측 배선이
  앞섰고(p = 0.037), 시드 30-49에서는 섞은 배선이 앞섰습니다).

하이퍼파라미터는 튜닝 시드 100-139에서만 탐색했고, 평가 시드 70-89에는 그대로 적용했습니다
([results/tuning.json](results/tuning.json)).

결과를 만든 발견은 세 가지입니다. 첫째, 초파리가 각 행동을 냄새처럼 맡고 비교하는
fly-blackjack의 선택 방식은 막대기의 상태를 행동 코드 밑에 묻어 버립니다. 미는 방향마다
버섯체를 따로 두자 이 문제가 해결되었습니다. 둘째, 도파민이 약화만 시킬 수 있는 시냅스는
결국 고갈됩니다. 실수할 때마다 약화로 처벌받으므로 쓸모 있는 시냅스까지 0으로 가라앉고
다시는 돌아오지 않습니다. 반대편 도파민 집단이 흔적이 남은 시냅스를 회복시키도록
허용하자(push-pull), 제자리에 멈춰 있던 초파리가 수백 걸음 동안 막대기를 세우게 되었습니다.
셋째, 버섯체 하나가 제한된 시냅스로 표현할 수 있는 가치는 약 −0.6에서 +0.7 사이에 불과한데,
넘어짐의 가치는 −1이고 기록을 길게 넘는 경우의 가치는 +10까지 올라갑니다. 결과의 크기를 이
범위 쪽으로 줄이자(원래의 0.3배) 학습이 더 빨라지고 시드 사이의 편차도 줄었습니다. 다만 너무
많이 줄이면(0.1배) 한쪽 가치가 처벌보다 아래로 가라앉아, 초파리가 한쪽으로만 미는 상태에
고착되었습니다.

보상 설계는 사람에게 빗댄 아이디어에서 나왔습니다. 막대기가 넘어지면 처벌하고, 초파리가
최근 기록을 넘어서는 순간부터 매 걸음 보상을 줍니다. 최고 기록이 5초인 사람이 6초째에
짜릿함을 느끼는 것과 같은 원리입니다. 이 기록 보상을 없애도 할인율이 짧으면
(γ = 0.95에서 187) 초파리는 여전히 학습했지만, 튜닝된 할인율(γ = 0.99)에서는 튜닝 시드
다섯 개 중 세 개에서 무너졌습니다(91). 기록을 더 느리게 갱신하거나 버틴 걸음마다 고정된
보상을 주는 방식도 결과가 더 나빴습니다(가설 16).

#### 500을 향해

초파리가 195를 넘은 뒤 목표를 500걸음 상한으로 올렸습니다. 진단해 보니 학습을 마친 초파리의
에피소드 중 58%는 막대기가 넘어져서가 아니라 수레가 트랙 밖으로 나가서 끝났고, 항상 더 나은 쪽을
고르게 해도 확률적으로 고를 때보다 나아지지 않았습니다. 아래 표는 따로 적지 않았다면 튜닝 시드
열 개에서 3,000 에피소드씩 돌린 결과입니다. 가설 24, 30-31, 32-33은 기록 보상과 마찬가지로
프로젝트 작성자의 아이디어입니다.

| # | 가설 | 바꾼 것 | 튜닝 시드 | 판정 |

초파리를 234에서 393까지 끌어올린 발견은 세 가지가 더 있습니다. 첫째, 자세 보상은 밀기가
막대기를 기울이거나 수레를 중심에서 멀어지게 하는 순간 바로 알려 줍니다. 수백 걸음 뒤 에피소드가
끝날 때까지 기다리지 않아도 됩니다. 둘째, 잦아드는 가소성은 균형 잡기를 익힌 초파리가 그것을
다시 잊지 않게 해 줍니다. 셋째, 탐색입니다. 초파리는 두 가치가 비슷한 곳에서만 탐색했으므로,
절반의 상태에서는 반대쪽을 한 번도 시도하지 않았고, 확신하지만 틀린 가치는 끝내 교정되지
않았습니다. 선택의 2%를 자발적으로 바꾸자 그런 가치가 교정되면서 트랙 이탈이 44%에서 28%로 줄고,
튜닝 점수가 416에서 440으로 올랐습니다.

**평가 시드는 다섯 번 소모되었으며, 모든 소모 내역을 여기에 밝힙니다.** 시드 0-9로는 push-pull
초파리를 결과 크기 1.0에서(194), 이어서 0.1에서(115, 고착) 평가했습니다. 시드 10-29로는 원래
설계의 탐색이 다른 모든 조건의 기록 보상 크기까지 정해 버린 실행을 평가했습니다(0.1 대신 0.5;
양쪽 버섯체 초파리 162.5). 보상은 과제의 일부이므로 이제는 고정하고 탐색하지 않습니다. 시드
30-49로는 시드 40개로 튜닝한 초파리를 1,000 에피소드 후에(191.7), 시드 50-69로는 2,000 에피소드
후에(233.8) 평가했고, 후자가 첫 목표인 195를 넘었습니다. 맨 위의 수치는 이전 실험이 한 번도
건드리지 않은 시드 70-89에서 나왔습니다.

### 작동 방식

**커넥톰 절편.** `fly-cartpole extract`는 공식 MaleCNS v1.0 flat connectome을 내려받아 양쪽
버섯체를 추려 냅니다. 오른쪽에는 더듬이엽 투사 뉴런(PN) 343개, PN 입력과 MBON 출력을 모두
가진 케년 세포(KC) 1,912개, 버섯체 출력 뉴런(MBON) 49개, 그리고 그 MBON에 시냅스를 맺는
PAM·PPL1 도파민 뉴런(DAN) 332개가 있습니다. 왼쪽에는 PN 343개, KC 1,893개, MBON 48개가
있습니다. 모든 연결은 시냅스 수를 그대로 유지하고, 각 세포가 받는 입력의 합은 1로
정규화합니다. KC 하나는 평균 5.8개의 PN에게서 입력을 받으며, 이는 문헌과 일치합니다. 추려 낸
결과는 `data/mb_right.npz`와 `data/mb_left.npz`로 커밋되어 있습니다.

**두 쪽, 두 행동.** 왼쪽 버섯체는 왼쪽으로 미는 행동의 가치를, 오른쪽 버섯체는 오른쪽으로
미는 행동의 가치를 매깁니다. 두 버섯체는 같은 상태를 듣지만, 자신이 어느 행동을 대표하는지는
전달받지 않습니다.

**인코더.** 사구체(PN 그룹)들이 CartPole의 상태 변수 네 개를 가우시안 조율 곡선으로 나누어
맡습니다. 같은 사구체에 속한 PN들은 함께 발화합니다.

**케년 세포.** PN 활동에 실측 PN→KC 행렬을 곱하고, 상위 5%의 KC만 발화시킵니다(APL 뉴런
대신 k-winners-take-all을 사용합니다).

**가치와 선택.** 도파민 입력 중 PPL1(처벌) 도파민이 우세한 MBON은 접근으로, PAM(보상) 도파민이
우세한 MBON은 회피로 분류합니다(Aso et al. 2014). 각 쪽의 가치는 접근 MBON 출력에서 회피 MBON
출력을 뺀 값이며, 초파리는 `sigmoid(beta * (left - right))`의 확률로 한쪽을 고릅니다. 선택의
2%는 가치를 완전히 무시합니다(실제 초파리가 보이는 자발적 행동; Maye et al. 2007). 그래서 초파리가
포기한 쪽도 다시 시도될 기회를 얻습니다.

**보상.** 막대기가 넘어지면 PPL1 처벌을 주고, 에피소드가 최근 20 에피소드의 평균보다 길어진
뒤부터는 매 걸음 작은 PAM 보상을 줍니다. 여기에 매 걸음 자세 신호
`3 * (0.998 * phi(next) - phi(now))`를 더하며, `phi = -(각도 / 12°)² - (위치 / 2.4 m)²`입니다.
수직과 중심에 가까워지면 보상하고 멀어지면 처벌합니다(잠재 기반 보상 조형; Ng, Harada and
Russell 1999). 보상은 과제의 일부이므로 TD 기준 모델을 포함한 모든 조건이 같은 보상을 받습니다.

**예측 오차로서의 도파민.** 도파민은 보상 자체가 아니라 놀라움을 전달합니다:
`delta = scale * (reward - punishment) + gamma * expected next value - current value`. PAM은
`max(delta, 0)`만큼, PPL1은 `max(-delta, 0)`만큼 발화하며, `gamma = 0.998`입니다. 결과의
크기(0.1)는 초파리가 배워야 하는 가치를 제한된 시냅스가 표현할 수 있는 범위 안에 묶어 둡니다. 각
도파민 집단이 어디에 닿는지는 실측 DAN→MBON 배선에서 읽어 옵니다.

**Push-pull 가소성.** KC→MBON 시냅스는 0과 1 사이의 이득(gain)을 가지며 0.5에서 시작합니다.
감쇠하는 흔적(trace)이 선택된 쪽에서 어떤 KC가 활성화되었는지 기억합니다. 방출된 도파민은
자신이 닿는 구획에서 흔적이 남은 시냅스를 약화하고(Hige et al. 2015; Handler et al. 2019),
반대편 도파민 집단은 자신이 닿는 구획에서 흔적이 남은 시냅스를 회복시킵니다. 학습률은 경험이
쌓일수록 `0.05 / (1 + 에피소드 / 1000)`으로 잦아듭니다.

### 실측한 것과 지어낸 것

- **실측:** 모든 PN→KC, KC→MBON, DAN→MBON, MBON→DAN 연결과 그 시냅스 수, 각 MBON에서 어느
  도파민 집단이 우세한지, 세포체 위치.
- **지어낸 것:** 사구체 인코더, APL 뉴런 대신 쓴 k-winners-take-all, 발화율 단위, 미는
  방향마다 버섯체 하나씩 두는 구조, 이상화한 예측 오차 도파민, 반대 도파민에 의한 시냅스
  회복, 0.5에서 시작하는 제한된 이득, 잦아드는 가소성, 자발적 선택, 보상 설계와 그 자세 신호 및
  크기, 그리고
  [results/hyperparameters.json](results/hyperparameters.json)의 하이퍼파라미터.

### 한계

- 버섯체만 시뮬레이션합니다. 뇌의 다른 부분은 계산하지도, 그리지도 않습니다.
- 발화율 단위를 쓰며, 스파이크, APL, KC→KC 연결, MBON→MBON 연결은 없습니다.
- 초파리는 막대기를 잘 세우지만 완벽하지는 않습니다. 평균은 393걸음이고, 개체별로 162-500걸음
  사이에 흩어져 있으며, 같은 코드와 보상을 쓰는 TD 학습기는 완벽합니다.
- 자세 신호는 막대기가 넘어졌는지보다 더 많은 정보를 초파리에게 줍니다. 드문 결과만으로 배우는
  능력을 더 깨끗하게 보여 주는 것은 자세 신호가 없던 초파리입니다(시드 50-69, 2,000 에피소드
  후 233.8).
- 결과 크기, 자세 신호, 탐색, 학습 길이는 이전 평가가 목표에 못 미친 뒤에 정했습니다. 각 선택은
  먼저 튜닝 시드에서 검증하고 쓰지 않은 시드에서 평가했지만, 어떤 선택을 시도할지는 그 부족함이
  드러낸 사실에 이끌렸습니다.
- MBON의 접근·회피 분류는 구획 단위의 설명을 따랐으며, 개별적으로 특성이 밝혀진 MBON과
  대조하지는 않았습니다.
- 데이터셋 하나와 평가 시드 20개만 사용했습니다. 각 시드는 사구체를 상태 변수에 배정하는
  방식도 따로 뽑고 그 시드의 모든 조건이 이를 공유하므로, 시드 사이의 편차에는 이 배정과
  학습 잡음이 섞여 있습니다.

## 뷰어

```bash
python3 -m http.server -d web   # 그다음 http://localhost:8000 을 엽니다
```

뷰어는 반사 초파리를 실시간으로 돌립니다. 비행 회로의 모든 뉴런을 내보낸 결합 가중치로 브라우저에서
직접 시뮬레이션하며, 테스트가 그 조향을 Python 모델과 1e-9 이내로 맞춰 봅니다. 매 에피소드는
무작위 상태에서 시작합니다. 두 설정 모두 트랙 가운데 위의 줄무늬인 랜드마크를 포함합니다.
"fixed (every gain 1)"를 고르면 배선 그대로의 회로를, 기본값인 "self-tuned"를 고르면 초파리가 시드
0에서 600 에피소드 동안 스스로 조율한 이득을 볼 수 있습니다. 시드 0은 보기 좋은 시드를 고른 것이
아니라 기본값입니다(마지막 100 에피소드 평균 500걸음). 왼쪽 화면에는 수레, 조향 신호(오른쪽
b1·b2 활동과 왼쪽의 차이), 상대 이득이 나오고, 그 아래에는 같은 순간을 초파리 뒤에서 본 비행
장면이 나옵니다. 막대기의 기울기는 초파리 몸의 옆기울임이고, 평균곤·홑눈·HS 세포는 각자의 활동에
따라 빛나며, 수레가 움직이면 땅이 흘러가고, 초파리가 미는 쪽의 날개가 더 넓게 칩니다(초당 약
200번인 날갯짓을 느리게 그렸습니다). 오른쪽 화면에는 뇌와 복측 신경삭에
걸친 회로의 뉴런 5,459개가 MaleCNS 세포체 위치에 그려집니다. 평균곤(호박색), 홑눈(초록), HS 세포
(파랑), 사이 뉴런(회색), 날개 조향 운동 뉴런(자홍)이 각자의 활동에 따라 밝아집니다. 평균곤 구심
뉴런은 세포체가 신경계 바깥의 평균곤에 있으므로, 이 뉴런들과 위치가 기록되지 않은 몇몇 뉴런은
연결 대상 뉴런들의 세포체 평균 위치에 그립니다.

## 실행 방법

```bash
uv sync
uv run fly-cartpole extract-flight   # MaleCNS를 한 번 내려받습니다; data/flight.npz는 이미 커밋되어 있습니다
uv run fly-cartpole reflex-tune      # 튜닝 시드 100-109에서 자가 조율 학습률을 고릅니다
uv run fly-cartpole reflex-compare   # 반사 조건을 시드 160-179에서 실행하고 results/reflex/에 기록합니다
uv run fly-cartpole station-compare  # 랜드마크 초파리들을 시드 180-199에서 실행하고 results/station/에 기록합니다
uv run fly-cartpole export-flight    # 시드 0에서 초파리를 조율하고 web/data/flight.json을 기록합니다
uv run fly-cartpole extract          # 버섯체; data/mb_*.npz는 이미 커밋되어 있습니다
uv run fly-cartpole tune             # 튜닝 시드 100-139에서 버섯체 설정을 탐색합니다
uv run fly-cartpole compare          # 버섯체 조건을 시드 70-89에서 실행하고 results/에 기록합니다
uv run pytest
```

CPU 코어 12개에서 `reflex-tune`과 `reflex-compare`는 각각 1시간 30분 정도, `station-compare`는 50분
정도, `tune`은 2시간 40분
정도, `compare`는 1시간 35분 정도 걸립니다.
